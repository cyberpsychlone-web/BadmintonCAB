Badminton Court Allocation Board

📦 Requirements

Windows Application

  • A Standard Web browser (Microsoft Edge or Google Chrome)

MacOS Application

  • A Standard Web browser (Safari or Google Chrome)
  • Python 3.11 virtual environment
  • Flask

Install Flask (if not already installed):

pip install flask

🚀 How to Run

Windows Application

  1. Double-click BadmintonCAB.exe to launch the Badminton Court Allocation Board.
  2. This will:
    • Start the scheduling app
    • Automatically open your default web browser at http://127.0.0.1:5000
  3. Once open, enter player names, court count, match time, and enjoy!

MacOS Application

  1. Place all files in the same folder as your Python3.11 venv:
    • app.py
    • BadmintonScheduler_Debug.command
    • CourtScheduler
    • templates/index.html
    • static/beep.mp3
    • static/icon1.png
    • readme.html (optional)
  2. Double-click BadmintonScheduler_Debug.command or its alias in the desktop CourtSchedulerto launch the Badminton Scheduler.
  3. This will:
    • Start the scheduling app
    • Automatically open your default web browser at http://127.0.0.1:5000
  4. Once open, enter player names, court count, match time, and enjoy!

📝 Features

  • Assign players randomly to available courts.
  • Pick players from a Players.csv file.
  • Automatic match timer with progress bar.
  • Custom match and break durations.
  • Custom court numbers assignment.
  • Track the number of shuttle corks used during the session.
  • Audible buzzer and "Time’s Up" message.
  • Player rest rotation fairness logic.
  • Match history log saved to match_history_log.csv.
  • Reset button to clear history and memory.
  • Mobile-friendly user interface.

📁 Match Log File

Each round is recorded in:

match_history_log.csv

This file contains round number, time, players on each court, resting players, and duration.
